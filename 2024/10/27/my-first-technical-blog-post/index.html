初衷

為什麼要開始寫技術部落格？

作為一名後端工程師，我一直渴望有一個屬於自己的平台來記錄學習過程中的每一步。這不僅僅是追蹤成長的軌跡，更是希望能通過撰寫和整理知識來鞭策自己持續學習。當日常工作中遇到挑戰或解決棘手的問題時，把這些經驗寫成文章，不僅加深了理解，也讓未來回顧時更加方便，甚至可能幫助到和我有相似經歷的開發者們。

精進全端技能

作為一名後端工程師，我一直感到在後端開發中缺乏一種「看得見」的成果呈現方式。僅僅靠後端的程式碼與邏輯，往往難以清楚展示自己的技術深度和實力。思索之下，建立一個技術部落格成為了最佳選擇。通過從無到有地架設一個完整的網站，不僅讓我得以展示所學，還能讓這個網站成為我成長歷程的見證，更進一步地提升了我在全端開發中的綜合技能。

在架設部落格的過程中，我逐步發現前端開發比想像中更需要細膩的理解。從最基礎的 HTML 和 CSS 開始，深入到 JavaScript 和 Node.js 的應用，每一步都需要大量的查閱資料和不斷試錯。透過這個過程，我逐漸掌握了 DOM 操作、事件處理、樣式微調等技術細節。雖然這些前端的細節探索有時繁瑣，但也帶來了滿滿的成就感，讓我對前後端的整合有了更全面的理解。這段深耕的過程不僅提升了我的技能，也讓我更堅信這條全端開發之路的價值。

自我介紹

我是 Ken Hsu，後端開發工程師，專注於以下技術領域：

  • 作業系統：Ubuntu (Linux)
  • 資料庫：MySQL、PostgreSQL、Oracle、Redis
  • 後端框架：Python Flask，並善於使用 async 技術以優化 I/O 密集型應用的並發處理
  • 前端技能：HTML, CSS,SCSS, Bootstrap, Javascript, Vue.js
  • 任務隊列與異步處理：使用 Celery 進行任務隊列管理，讓後端處理能夠非同步執行並提升效率
  • 容器化技術：Docker、Docker Compose
  • CICD: Gitlab
  • 伺服器配置：Nginx 作為反向代理和負載均衡
  • API 測試：Postman
  • 資料處理：Pandas
  • 網路爬蟲：Beautiful Soup、Selenium
  • 影像辨識：pytesseract
  • AI 應用：使用 GPT 模型串接 RAG 服務
  • 第三方服務整合：
    • LINE
    • Google API
    • 綠界科技
  • 開發工具：ngrok 用於本地服務外網測試

成長及專案經驗

2022 年 iThome 鐵人賽：挑戰自我、持續精進

在 2022 年，我參加了 iThome 鐵人賽，這是一項每日持續挑戰的技術分享賽事。為了完成主題為「三十天全端工程師挑戰」的教學影片，我在 Raspberry Pi 上架設了簡易的購物商城，實現了基本的全端開發功能。這段經歷讓我在高度專注的狀態下學習，幾乎是「不眠不休」地完成了整個項目，讓我快速掌握了技術應用並鍛煉了專案管理能力。

Raspberry Pi 部署服務：結合硬體及軟體

在學習後端技術之初，我利用 Raspberry Pi 架設了小型伺服器，並部署了網路爬蟲程式來收集數據並進行自動化處理。這是我第一次將技術應用於硬體平台，從安裝系統到配置網路，每一個步驟都讓我深刻體會到系統架設的細緻與成就感。這項經驗不僅讓我理解了硬體伺服器的部署，也大大提升了我處理網路爬蟲與數據處理的能力。在2024年, 甚至因為使用爬蟲爬取租屋網站, 獲得了Joeman的採訪。

GitLab CI/CD 學習：實踐自動化部署

為了加強 CI/CD 能力，我利用假日時間參加了 GitLab CI/CD 的相關課程。在課程中，掌握了 Docker、Docker Compose 以及 GitLab 自動化部署的技能，並將其應用於工作專案中，大大提升了開發和部署效率。這項學習經歷讓我能夠以更自動化的方式來進行版本控制與部署，也進一步強化了我的技術架構設計能力。

AI 應用學習：搭建 GPT 串接服務的 Side Project

在 AI 領域的應用中，我創建了一個 Side Project，並租用雲端主機架設後端伺服器，串接 GPT 的 API，讓使用者可以註冊、訂閱並客製化知識內容，還能串接到特定的社群媒體平台。這項專案還在持續開發中，但我已經收穫了不少實踐經驗，並深入了解了 AI 與應用程式的整合流程。

前端學習：進一步拓展技能

雖然我的主力是後端開發，但在項目過程中，我開始學習 JavaScript 和 Vue 框架的應用。通過這些學習，我逐步掌握了前端設計的基礎，並學會了如何與後端進行無縫對接。這種多方面的技能拓展讓我在技術開發上更加游刃有餘，也讓我對技術整合有了更深的理解。

心得

不斷學習的動力

這是我的第一篇技術部落格文章，象徵著全新的開始和一種對自己的承諾：我會堅持記錄每一次學習和成長，不斷督促自己進步。未來希望這裡能成為自己技術成長的日誌，記錄探索 AI、後端和整合應用的每一步，也能成為其他開發者的學習資源。

技術成長的印記

架設部落格的過程中，我意識到自己的不足，同時也被激發了對新技術的好奇心和動力。無論過程多繁瑣，這份記錄讓我看見自己的成長，而這僅僅是開始。我期望未來在這裡留下更多學習的足跡，提醒自己無論工作多忙碌，學習的步伐都不能停下來。

感謝這一天，為我揭開了技術紀錄的新篇章。期待接下來的每一步，成為我技術之路上堅實的印記。

English Version

Original Intention

Why Start Writing a Technical Blog?

As a backend engineer, I have always wanted a platform of my own to record every step of my learning journey. This is not only about tracking my growth, but also about pushing myself to keep learning through writing and organizing knowledge. When I encounter challenges at work or solve difficult problems, turning those experiences into articles helps me deepen my understanding. It also makes future review easier, and it may even help other developers who have gone through similar experiences.

Improving Full-Stack Skills

As a backend engineer, I have often felt that backend development lacks a visible way to present results. Backend code and logic alone are often not enough to clearly demonstrate technical depth and capability. After thinking about it, building a technical blog became the best choice. By creating a complete website from scratch, I could not only showcase what I had learned, but also turn the website itself into a record of my growth, further improving my overall full-stack development skills.

During the process of building this blog, I gradually realized that frontend development requires more delicate understanding than I had imagined. From basic HTML and CSS to JavaScript and Node.js, every step required a lot of research and repeated trial and error. Through this process, I gradually learned technical details such as DOM manipulation, event handling, and style tuning. Although exploring these frontend details can sometimes be tedious, it also brings a strong sense of achievement and gives me a more complete understanding of frontend-backend integration. This hands-on process not only improved my skills, but also strengthened my belief in the value of the full-stack path.

Self Introduction

I am Ken Hsu, a backend engineer focused on the following technical areas:

  • Operating system: Ubuntu (Linux)
  • Databases: MySQL, PostgreSQL, Oracle, Redis
  • Backend frameworks: Python Flask, with experience using async techniques to optimize concurrent processing for I/O-intensive applications
  • Frontend skills: HTML, CSS, SCSS, Bootstrap, JavaScript, Vue.js
  • Task queues and asynchronous processing: Using Celery to manage task queues so backend processing can run asynchronously and more efficiently
  • Containerization: Docker, Docker Compose
  • CI/CD: GitLab
  • Server configuration: Nginx as a reverse proxy and load balancer
  • API testing: Postman
  • Data processing: Pandas
  • Web scraping: Beautiful Soup, Selenium
  • Image recognition: pytesseract
  • AI applications: Integrating GPT models with RAG services
  • Third-party service integration:
    • LINE
    • Google API
    • ECPay
  • Development tools: ngrok for exposing local services during testing

Growth and Project Experience

2022 iThome Ironman Challenge: Challenging Myself and Improving Continuously

In 2022, I participated in the iThome Ironman Challenge, a technical sharing event that requires continuous daily output. To complete my tutorial video series titled “Thirty Days Full-Stack Engineer Challenge,” I built a simple shopping mall on a Raspberry Pi and implemented basic full-stack development features. This experience pushed me to learn with intense focus. I nearly worked around the clock to complete the whole project, which helped me quickly grasp practical technical applications and strengthen my project management ability.

Deploying Services on Raspberry Pi: Combining Hardware and Software

When I first started learning backend development, I used a Raspberry Pi to build a small server and deployed a web crawler to collect data and automate processing. This was my first time applying software skills on a hardware platform. From installing the system to configuring the network, every step gave me a deeper appreciation of the detail and sense of achievement involved in system setup. This experience not only helped me understand hardware server deployment, but also greatly improved my ability to handle web scraping and data processing. In 2024, I was even interviewed by Joeman because I used a crawler to collect rental housing information.

Learning GitLab CI/CD: Practicing Automated Deployment

To strengthen my CI/CD skills, I used my weekends to attend GitLab CI/CD courses. During the course, I learned Docker, Docker Compose, and GitLab automated deployment, then applied those skills to work projects, significantly improving development and deployment efficiency. This learning experience allowed me to manage version control and deployment in a more automated way, while also strengthening my ability to design technical architecture.

AI Application Learning: Building a GPT Integration Side Project

In the field of AI applications, I created a side project and rented a cloud server to host the backend. I integrated GPT APIs so users can register, subscribe, customize knowledge content, and connect the service to specific social media platforms. This project is still under development, but I have already gained a lot of practical experience and a deeper understanding of how AI and applications integrate.

Frontend Learning: Expanding My Skills Further

Although my main focus is backend development, I started learning JavaScript and the Vue framework during projects. Through this learning, I gradually built a foundation in frontend design and learned how to integrate smoothly with backend services. This broader skill expansion has made me more flexible in technical development and given me a deeper understanding of system integration.

Reflections

The Motivation to Keep Learning

This is my first technical blog post. It marks a new beginning and a promise to myself: I will continue recording every step of learning and growth, and keep pushing myself forward. I hope this place can become a diary of my technical growth, documenting each step of exploring AI, backend development, and integrated applications, while also becoming a learning resource for other developers.

Traces of Technical Growth

While building this blog, I became aware of my own shortcomings, but I was also inspired with curiosity and motivation for new technologies. No matter how tedious the process may be, this record lets me see my own growth, and this is only the beginning. I hope to leave more learning footprints here in the future, reminding myself that no matter how busy work becomes, the pace of learning must never stop.

Thank you to this day for opening a new chapter in my technical record. I look forward to every step ahead becoming a solid mark on my technical journey.
